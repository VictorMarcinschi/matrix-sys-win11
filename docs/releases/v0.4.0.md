The first public release of MatrixSys: a native, offline 3D visualizer of a Windows 11 machine.

![Processes tab](https://raw.githubusercontent.com/VictorMarcinschi/matrix-sys-win11/v0.4.0/docs/screenshots/processes.gif)

## Download

- **MatrixSys-Setup-v0.4.0.exe**: the installer. It installs to Program Files and can add shortcuts, the optional background capture service and the optional web page renderer.
- **MatrixSys-v0.4.0-portable.zip**: unzip anywhere and run `MatrixSys.exe`. Nothing is installed.
- **SHA256SUMS.txt**: checksums of both.

Both are built by GitHub Actions from the tagged source; the build log is in the repository's Actions tab.

## What it shows

- **Processes**: the process tree in 3D, with lanes for the data processes exchange. Size can stand for memory, lane traffic or CPU load.
- **Network**: processes, their open ports and the remote hosts they talk to; one dot per packet when capture is live.
- **Files, Disks, Devices, Memory**: open files per process, a folder treemap of every partition, connected hardware and its traffic, memory per program.
- **Trace**: type a host, an IP address or a URL; see the name lookup, every router on the way and the whole conversation (ICMP, TCP, HTTP, HTTPS, DNS) as orbs, each message decoded. Full speed with replay, or step by step.

Plus a packet viewer, a process memory viewer, reverse DNS and owner lookups, and actions such as suspend, kill, priority and firewall block. Dangerous actions are red and ask first.

## Before you run it

- **Windows 11, 64-bit.** Windows 10 may work but is untested.
- **SmartScreen will warn** that the publisher is unknown, because the files are not code-signed yet. Choose *More info* and *Run anyway* if you trust this build; the checksums let you compare with a build of your own.
- **Antivirus tools may be suspicious**, because the app captures packets, reads other processes' memory when you open the memory viewer, and can end processes when you ask it to.
- **Real traffic needs administrator rights** or the optional service; without either the app shows estimates and says so.
